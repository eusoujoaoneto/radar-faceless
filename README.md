# Radar Faceless

Painel de análise de canais faceless do YouTube: desempenho, segredos do sucesso, risco de desmonetização (políticas do YouTube), blueprint de modelagem e dossiê em PDF (celular ou A4).

Site estático publicado pelo GitHub Pages.

## Como adicionar um canal
1. Salve o perfil em `profiles/<slug>.json` e as thumbnails em `thumbs/<slug>.json`.
2. Acrescente o `<slug>` na lista de `profiles/index.json`.

Receitas mostradas são estimativas, não dados do YouTube Studio.
